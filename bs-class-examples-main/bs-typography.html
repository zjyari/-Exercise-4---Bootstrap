9. m: margin

This box has margin on all sides using m-4.

m means margin. For example: m-0, m-1, m-2, m-3, m-4, m-5.

10. p: padding

This box has padding on all sides using p-4.

p means padding. Padding creates space inside the element.

11. w: width

w-25
w-50
w-75
w-100

w-50 means the element takes 50% of the parent element's width.

12. vw: viewport width

This box uses vw-100, so it tries to take 100% of the viewport width.

vw is based on the browser window width, not the parent element width.

13. h: height

h-25

h-25 means the element takes 25% of the parent element's height. The parent must have its own height defined first.

14. vh: viewport height

This box uses vh-100, so it takes 100% of the viewport height.

vh is based on the browser window height.
